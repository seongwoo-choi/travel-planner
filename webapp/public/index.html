        LLM 인증/실행 옵션

        ChatGPT/Claude 로그인은 이 웹앱에 API 호출 권한을 넘겨주지 않습니다. 공식 콘솔에서 API key를 발급한 뒤, 이 요청에만 임시로 사용할 수 있습니다.

        1. 서버 기본 설정: 운영자 `.env` 키로 실행되어 운영자 계정에 과금됩니다.
        2. 다른 사람에게 공유: 사용자가 자신의 API key를 요청 1회용으로 넣어야 그 사용자 계정으로 과금됩니다.
        3. OAuth 로그인: 현재 일반 OpenAI/Anthropic API 호출 권한을 웹앱에 위임하는 공개 흐름으로 쓰지 않습니다.

        저장된 플랜

        고정한 플랜은 목록에서 표시됩니다. `고도화 후보`는 품질 확인 또는 미점검 플랜을 우선순위 순서로 모으고, `긴급 후보`는 우선도 80 이상 플랜만 모읍니다. `품질 확인`은 보강할 항목이 남은 플랜을 확인 항목이 많은 순으로, `품질 미점검`은 자동 품질 점검이 아직 없는 플랜을 보여주고, `품질 악화`와 `품질 개선`은 직전 버전 대비 확인 항목이 늘거나 줄어든 플랜을 보여줍니다. 고도화 후보에서는 단건 TODO와 상위 후보 3/5/10개 TODO를 복사할 수 있습니다. 상세 화면에서 고정하거나 해제할 수 있습니다.
